# ◈ Relational Database Table Operations
**Course ID**: `268-[DF]-Lab`

## 🎯 Data Objective
This lab focuses on the fundamentals of relational database design. The objective is to construct normalized table schemas, define primary/foreign key relationships, and manage data types to ensure integrity and efficient query performance.



## ⚙️ Schema & Execution Logic
* **Schema Design:** [E.g., "Designed a normalized database schema, defining optimal data types and constraints to minimize redundancy."]
* **Table Implementation:** [E.g., "Executed DDL statements (`CREATE TABLE`, `ALTER TABLE`) to establish structure, ensuring all primary and foreign key constraints were correctly mapped."]
